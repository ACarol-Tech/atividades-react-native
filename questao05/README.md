# Questão 05 - Simulador Bancário

Simula uma conta bancária com saldo inicial de R$ 1.000,00.

## Funcionalidades

- Depósito e saque
- Bloqueia valores vazios, zero ou negativos
- Bloqueia saque maior que o saldo
- Valores formatados em reais (R$)

## Como executar

1. Acesse [snack.expo.dev](https://snack.expo.dev)
2. Substitua o conteúdo do `App.js` pelo código desta pasta
3. Execute no navegador (Web) ou no celular pelo app **Expo Go**
